Kiến trúc memory

Mỗi loại memory trả lời một câu hỏi khác nhau.

SHORT-TERM

“Vừa nói gì?”

Turn gần nhất, summary và sliding window. Chạy local để nhanh.

LONG-TERM

“User là ai?”

Zep Context Block, facts, preference và task dài hạn.

EPISODIC

“Đã xảy ra chuyện gì?”

Episode cụ thể trong các session trước, có provenance.

SEMANTIC

“Quy tắc chung là gì?”

Standalone graph chứa kiến thức domain không thuộc riêng user.

Kết luận · nhận xét

Hybrid memory là lựa chọn thực tế.

  • Local short-term cho tốc độ phản hồi.
  • Zep cho durable memory và graph retrieval.
  • Redis/Qdrant làm baseline hoặc local fallback.
  • Privacy phải đi cùng memory: có thể forget user.

Thông điệp cuối

Agent tốt không phải agent nhớ nhiều nhất. Đó là agent biết lúc nào cần nhớ gì, lấy từ đâu và đưa bao nhiêu vào context.

Kết thúc bằng thông điệp này, sau đó mời người nghe đặt câu hỏi về trade-off giữa managed memory và tự xây hệ thống.
